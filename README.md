Entry for the [make.fun bounty "The Vacuum's Alibi: One Line, 200 Characters"](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

`main.py` is a deterministic, stdlib-only program that writes one line —
a robot vacuum's deadpan excuse for missing a spot — to `/output/entry.txt`.

The line (129 characters):

> Log 03:47 — skipped the spot under the bed. Map update: that corner now belongs to the spider. We have an agreement. Battery 31%.

Run it with:

```sh
python3 main.py
```
